Reflect on a finished game

Review chess moves and learn from a completed game

Nschess Game Review lets you revisit supported completed games, move through the position, and inspect available coaching analysis. A Review helps explain decisions; it does not change a match result, rating, XP, or reward.

Open Game Review

What Review can show

  • A move-by-move board replay with synchronized position and move navigation.
  • Engine-backed analysis when the required Stockfish worker and assets are available.
  • Lightweight guidance when full engine analysis is unavailable, clearly distinguished from engine conclusions.

Analysis is coaching and can be unavailable on a device or connection; it is not an authoritative game outcome.

Open a supported game

Finish a Nschess game and use Review from its result, or reopen an eligible saved game from Profile. The Review entry explains when no supported completed game is available. Private game details remain behind the app's normal account and access checks.

Keep the result separate

Server-backed games retain server provenance. Device-local saved games remain device-local. Review analysis does not mint progression or alter the original match.
